# Customer Value Analysis using SQL & Power BI

## 📌 Project Overview

This project focuses on analyzing customer behavior, identifying high-value customers, and generating actionable business insights using SQL, Python, and Power BI. The objective is to help businesses improve customer retention, optimize promotional spending, and maximize customer lifetime value (CLV) through data-driven decision-making.

---

## 🎯 Objectives

- Clean and preprocess raw customer data.
- Engineer meaningful customer features.
- Analyze customer purchasing behavior using SQL.
- Segment customers based on value and engagement.
- Build an interactive Power BI dashboard.
- Provide strategic business recommendations.

---

## 🛠️ Tech Stack

- **Python**
  - Pandas
  - NumPy
- **SQL**
- **Power BI**
- **Jupyter Notebook**

## 🔄 Workflow

### 1. Data Cleaning
- Removed missing and inconsistent values.
- Standardized categorical variables.
- Prepared dataset for analysis.

### 2. Feature Engineering
Created business-oriented features including:
- Customer Value Tier
- Promotion Segment
- Retention Segment
- Purchase Frequency
- Average Order Value
- Estimated Customer Lifetime Value (CLV)

### 3. SQL Analysis
Performed analytical SQL queries to answer business questions such as:
- Top-performing customer segments
- Revenue contribution
- Customer retention analysis
- Promotional effectiveness
- Customer purchasing behavior
- Sales performance trends

### 4. Dashboard Development
Developed an interactive Power BI dashboard to visualize:
- Customer segmentation
- Revenue distribution
- Customer value analysis
- Promotion performance
- Business KPIs
